# Changelog

## 1.0.1
- Примеры: описание в начале каждого примера на русском, казахском и английском.

## 1.0.0
- Первый выпуск: RC522 по SPI, драйвер внутри (общественное достояние, взят из библиотеки MFRC522 1.4.12 с переименованием класса).
- `available()` срабатывает один раз за поднесение карты, повтор той же карты с паузой; UID строкой, числом, тип карты.
- Список разрешённых карт на 16 штук (`addCard`, `isAllowed`, `addCurrent`, `printCards`), разбор UID в разных написаниях.
- Проверка связи с RC522 при `begin()` (нет связи, клон), понятные ошибки и `diagnose()` на русском, казахском и английском.
